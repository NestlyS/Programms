# SKY SNAKE — Turbo Flight

A small browser-based 3D flying snake game with third-person chase camera, obstacle course, checkpoints, and turbo boost.

## Play

Open [index.html](./index.html) in a modern desktop browser. No dependencies, installation or server required.

## Controls

| Key | Action |
| --- | --- |
| W | Ascend |
| S | Descend |
| A | Turn left |
| D | Turn right |
| Shift (hold) | Accelerate (9.2 → 19 m/s) |
| P or Esc | Pause |
| ↻ button | Restart |

## Features

- Continuous smooth flight in 3D with a following camera.
- Snake body follows the actual flight path and grows after collecting crystals.
- Sky City obstacles: bridge, buildings, pillars.
- 7 checkpoint rings and lap timer.
- Collision detection for the body, obstacles and arena limits.
- Predictive red danger vignette near boundaries, including turbo speed.
- Adjusted checkpoint layout so rings are not inside buildings.

This is a self-contained HTML5 Canvas prototype created collaboratively in ChatGPT.
